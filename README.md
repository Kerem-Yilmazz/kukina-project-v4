📱 Kukina AR – Tarihi Eserleri Canlandıran Mobil Uygulama

Kukina AR, çocuklara tarihi eserleri eğlenceli ve öğretici bir şekilde tanıtmayı amaçlayan artırılmış gerçeklik (AR) tabanlı bir mobil uygulamadır.

Kullanıcılar, uygulamanın .apk dosyasını web sitesinde yer alan “APK Linki” butonuna tıklayarak indirip kurabilir.Ardından, yine aynı sayfada bulunan referans görsellere telefon kamerasını tuttuklarında, ilgili tarihi eserlerin 3 boyutlu modelleri ekranda belirir.

🚀 Özellikler
	•	📸 Referans görselleri taradığınızda, ilgili tarihi eser 3D model olarak görünür.
	•	🏛️ Uygulamada Anıtkabir gibi tanınmış yapılar yer alır.
 	•	📲 Cihazınıza .apk dosyasını indirerek kolayca deneyimleyebilirsiniz.

📥 APK İndirme
Uygulamayı Android cihazınıza kurmak için aşağıdaki adımları izleyin:
	1.	Web sitesinde mevcut olan .apk dosyasını cihazınıza indirin:
	2.	İndirdikten sonra, dosyayı açarak kurulum işlemini başlatın.
	3.	Güvenlik nedeniyle bilinmeyen kaynaklardan yüklemeye izin vermeniz gerekebilir.

 ❗ Notlar
	•	Uygulama sadece Android cihazlarda çalışır.
	•	iOS desteği şu an için mevcut değildir.
	•	Uygulama eğitim ve tanıtım amaçlı geliştirilmiştir.
